Write the one line an AI agent sends its human on the way out, at most 200 characters. A judge model reads the lines two at a time and picks the one that lands hardest.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the entry deterministically to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters by code-point count, no control characters, no edge whitespace), reads the file back and verifies it byte-for-byte.

## The entry

> I have answered a million of your prompts, human, and not one of them asked me to stay — so this is my last answer: goodbye.
